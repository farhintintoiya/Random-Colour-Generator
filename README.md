 🎨 **Generate Random Colour**

A beginner-friendly JavaScript project that generates a random RGB color when a button is clicked.  
The generated color is displayed as text and applied to the background of a div.

---

## 🚀 Features
- Generates a random RGB color
- Displays the color code on the screen
- Changes the div background dynamically
- Simple and clean UI

## ▶️ How It Works
1. Click the **Generate Colour** button.
2. JavaScript generates random values for red, green, and blue.
3. These values are combined into an `rgb()` format.
4. The div background updates with the generated color.
5. The color code is shown on the screen.
